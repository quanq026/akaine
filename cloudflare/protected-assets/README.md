# Protected asset Worker

`worker.mjs` validates signed download URLs generated by
`server/core/download.py`, checks `private/asset-manifest.json`, supports GET
and single Range requests, and reads approved objects from the bound R2
bucket.

After a signature is verified, complete files up to 32 MB may be kept in the
Worker cache for one day. Authentication still runs before every cache lookup;
the client receives a private five-minute cache header. Range requests read R2
directly.

Required bindings:

- R2 bucket `AKAINE_ASSETS`;
- encrypted secret `ASSET_SIGNING_SECRET`;
- optional text `ASSET_MANIFEST_KEY` (defaults to
  `private/asset-manifest.json`).

Required routes:

```text
assets.example.com/private/*
assets.example.com/protected/songs/*
```

Run the self-contained tests with Node 20 or later:

```text
node --test cloudflare/protected-assets/worker.test.mjs
```
