# Emulator-only Group visit experiment

These are exact source bytes from the isolated V2 QA overlay. They are not inputs
to the normal V35 release. Canonical runtime source and original media remain
unchanged. The existing monitor build overlays these headers into its private
owned source copy; the gate changes only the Group visit relocation and RX extent.

The first safe-read candidate culled collapsed offscreen headers but did not
improve 1% low. V2 reuses exact successful Node snapshots only during one callback
and batches known fields. Keep the strict shape, ownership, polygon, pending
layout and deferred transform guards. Runtime performance and reveal acceptance
are required before moving this experiment into normal release inputs.

Native version-specific offsets are intentional. Build assets, opaque headers,
APKs, native binaries, machine maps and device/account data stay outside Git.
