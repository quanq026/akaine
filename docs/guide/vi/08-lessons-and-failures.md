# Lỗi thường gặp

[English](../08-lessons-and-failures.md) | Tiếng Việt

- Không thấy bundle: kiểm AppVersion, phiên bản manifest và SHA-256 theo [chương server](05a-install-game-server.md).
- Tải xong nhưng không thấy bài: kiểm songlist, packlist và quyền acc theo [chương bot](05b-discord-bot.md).
- API hoạt động mà game không đăng nhập: kiểm hostname trong APK, sau đó kiểm đường dẫn API.
