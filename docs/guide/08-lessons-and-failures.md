# Troubleshooting

[Tiếng Việt](vi/08-lessons-and-failures.md)

- No bundle appears: check AppVersion, the manifest version and SHA-256 using [the server chapter](05a-install-game-server.md).
- A song is missing after download: check songlist, packlist and account access using [the bot chapter](05b-discord-bot.md).
- The API works but the game cannot sign in: check the hostname in your APK and then the API route.
