# QA-only geometry diagnostic source reference

These exact operator sources are archived for traceability. Their relativeHERE
layout and explicit private input paths belong to the original workspace paths
in PROVENANCE.json; do not run them from this directory. Source-only default
preparation and separate reviewed build bind the original core, monitor, SDK,
compiler/link inputs and full-register gates. Private semantic pins, binaries,
SDKs and media are not committed.

The four temporary hooks time the list geometry prepass and nestedgroup helper,
with fixed owner-thread aggregates and one log/10s. JNI reads the actual renderer
interval only at flush, outside the timed region. The gates lack newFDE metadata;
exceptions/unbalanced returns invalidate a window. This is accepted only for
the isolated QA emulator and must never be promoted to the phone/release.

Actual results show this prepass is small, not the entire menu frame bottleneck.
The accepted normal APK was restored after collection. The source here is not a
menu performance fix and does not change media quality, FPS caps or content.
